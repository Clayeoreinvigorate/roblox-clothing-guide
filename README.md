## 🚀 Step-by-Step Guide

The workflow below is based on the tutorial and is intended for Roblox clothing items that you own or are authorized to use.

### 1. 👕 Open the Roblox clothing page

Open the Roblox shirt or pants page for the item you are authorized to use.

### 2. 🖱️ Open Developer Tools

Right-click on the page.

Choose:

**Inspect**

Then open the:

**Network** tab.

### 3. 🔄 Refresh the page

Reload the page by pressing **Ctrl + R**.

Wait a few seconds for the Network requests to load.

### 4. 🔎 Find the relevant request

Look through the Network requests for the request related to the clothing item shown in the tutorial.

> 💡 The exact request may vary depending on the page, browser, and Roblox updates.

### 5. 📋 Copy the request information

If the tutorial asks you to copy request information, right-click the relevant request and select:

**Copy → Copy as PowerShell**

Avoid sharing copied request information publicly if it contains private or sensitive data.

### 6. 🌐 Open the website

Open:

**[RobloTools Shirt Copier](https://roblotools.com/shirt-copier/unc)**

Paste the required information and follow the instructions shown by the website.

## ❓ Troubleshooting

<details>
<summary><strong>🔎 I can't find the Network tab</strong></summary>

Open Developer Tools by pressing **F12**.

Then select **Network**.

</details>

<details>
<summary><strong>🔄 I can't find the request</strong></summary>

Refresh the page and wait until the Network list is populated.

The request name and position can change when Roblox updates its website.

</details>

<details>
<summary><strong>📋 "Copy as PowerShell" is not available</strong></summary>

Make sure you are right-clicking an actual network request in the **Network** panel.

</details>

<details>
<summary><strong>👕 The clothing item is not found</strong></summary>

Make sure the item is still available and that you have permission to use or process it.

</details>
